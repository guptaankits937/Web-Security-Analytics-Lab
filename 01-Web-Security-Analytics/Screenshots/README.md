# Web Security Analytics & Bot Traffic Investigation - Screenshots

This directory contains practical evidence captured during the Web Security Analytics & Bot Traffic Investigation project.

## Evidence

The screenshots document the major stages of the investigation, including:

- Apache web server configuration
- Custom security access logging
- Web endpoint validation
- Authentication failure testing
- Controlled HTTP 500 testing
- Security dataset generation
- Dataset validation
- Bash log analysis
- Python log parsing and processing
- SQL Server data validation and security analysis
- Power BI security analytics dashboard
- Power BI interactive client view
- Tableau security analytics dashboard

Only meaningful project evidence is retained.

Screenshots intended for the public repository are sanitized to avoid exposing credentials, passwords, usernames, hostnames, or unnecessary internal network information.

These screenshots support the practical steps and findings documented in the project README and detailed technical documentation.
